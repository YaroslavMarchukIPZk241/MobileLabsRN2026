# Звіт до лабораторної роботи №3

## Тема
Використання кастомних жестів у React Native та стилізація інтерфейсу мобільного застосунку.

## Мета
Навчитися працювати з жестами користувача у мобільному застосунку, реалізувати взаємодію через різні типи жестів та застосувати сучасні підходи стилізації у React Native.

## Опис застосунку
Було розроблено мобільний застосунок `Gesture Clicker`. Це невелика гра-клікер, у якій користувач взаємодіє з круглим об'єктом на головному екрані. За різні жести користувач отримує різну кількість очок. Також у застосунку є сторінка із завданнями та сторінка налаштувань.

## Реалізація жестів
У проєкті використано бібліотеку `react-native-gesture-handler`.

| Жест | Компонент | Результат |
|---|---|---|
| Коротке натискання | `TapGestureHandler` | Додає 1 очко |
| Подвійне натискання | `TapGestureHandler` з `numberOfTaps={2}` | Додає 2 очки |
| Довге натискання | `LongPressGestureHandler` | Додає 5 очок після утримання 3 секунди |
| Перетягування | `PanGestureHandler` | Дозволяє переміщати об'єкт |
| Свайп вправо / вліво | `FlingGestureHandler` | Додає випадкову кількість очок |
| Масштабування | `PinchGestureHandler` | Змінює розмір об'єкта та додає бонус |

## Реалізація сторінки завдань
Сторінка завдань показує список цілей, які користувач має виконати. Для кожного завдання відображається назва, короткий опис, прогрес і статус виконання. Завдання автоматично оновлюються після відповідних дій на головному екрані.

## Реалізація налаштувань
На сторінці налаштувань додано:
- перемикач світлої та темної теми;
- поточну статистику виконаних жестів;
- кнопку скидання прогресу.

## Стилізація
Для стилізації використано `styled-components`. Інтерфейс має картки, кольорові індикатори, адаптацію під світлу й темну тему та єдиний набір кольорів у файлі `src/theme/theme.ts`.

## Навігація
Навігацію реалізовано через `@react-navigation/native` та `@react-navigation/bottom-tabs`. У застосунку є три вкладки: гра, завдання та налаштування.

## Висновок
Під час виконання лабораторної роботи було створено мобільний застосунок на React Native, у якому реалізовано кілька типів жестової взаємодії: натискання, подвійне натискання, довге натискання, перетягування, свайпи та масштабування. Також було додано навігацію між екранами, список завдань із відображенням прогресу, сторінку налаштувань і підтримку світлої та темної теми.
