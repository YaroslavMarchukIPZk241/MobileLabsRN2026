 # 📱 MobileLabsRN2025

## 📖 Загальна інформація
Даний проєкт є результатом виконання лабораторної роботи з курсу мобільної розробки.  
Застосунок створено з використанням React Native та середовища Expo.

Основна ідея — продемонструвати базові принципи побудови мобільного застосунку:
роботу з екранами, навігацію та організацію структури проєкту.

Автор: Марчук Ярослав (ІПЗк-24-1)

---

## 🧰 Використані технології
- React Native
- Expo
- JavaScript
- React Navigation

---

## 🔍 Можливості застосунку
У проєкті реалізовано:
- декілька окремих екранів
- навігацію між ними
- відображення простого контенту
- базову структуру компонентів

---

## 🗂 Організація коду
Проєкт поділено на логічні частини:
- screens — основні екрани застосунку
- components — повторно використовувані елементи
- navigation — налаштування переходів між екранами
- assets — статичні файли (зображення тощо)

---

## ⚙️ Як запустити проєкт

### Підготовка
Перед запуском переконайтесь, що встановлено:
- Node.js
- npm або yarn
- Expo CLI (за потреби)

### Встановлення
Виконайте в терміналі:
npm install

### Запуск
Запустіть проєкт командою:
npm start

або:
expo start

---

## 📱 Тестування застосунку
Доступні варіанти запуску:
- через Expo Go на телефоні (QR-код)
- у браузері (web-версія)
- на емуляторі Android або iOS
